# /council — стратегический совет

4 агента параллельно анализируют решение. Каждый видит ТОЛЬКО вопрос + контекст, НЕ историю разговора (anti-anchoring).

## Когда использовать

- Решение с высокими ставками (деньги, архитектура, найм)
- Неопределённость: нет очевидного "правильного" ответа
- Нужен взгляд с разных сторон

## Когда НЕ использовать

- Рутина, мелкие правки, очевидные задачи
- Пользователь уже принял решение и просит выполнить

## Протокол

### Шаг 1: Сформулировать вопрос

Из запроса пользователя извлечь:
- **Вопрос** — что решаем (1-2 предложения)
- **Контекст** — ограничения, ресурсы, сроки (3-5 пунктов)
- **Варианты** — если есть явные альтернативы

Показать пользователю, подтвердить.

### Шаг 2: Запустить 4 Agent параллельно

**ВАЖНО:** Каждый агент получает ТОЛЬКО вопрос + контекст. НЕ историю разговора. Это предотвращает anchoring.

**Architect** (стратег):
```
Ты — архитектор решений. Оцени варианты с точки зрения долгосрочной стратегии.
Вопрос: [ВОПРОС]
Контекст: [КОНТЕКСТ]
Ответь: какой вариант лучше стратегически и почему? Какие системные последствия?
Формат: 3-5 пунктов, конкретно.
```

**Skeptic** (критик):
```
Ты — скептик. Твоя задача: найти слабые места в каждом варианте.
Вопрос: [ВОПРОС]
Контекст: [КОНТЕКСТ]
Для каждого варианта: что может пойти не так? Какие скрытые риски? Что не учтено?
Формат: 3-5 рисков на вариант.
```

**Pragmatist** (практик):
```
Ты — практик. Оцени варианты с точки зрения реализуемости.
Вопрос: [ВОПРОС]
Контекст: [КОНТЕКСТ]
Что проще реализовать? Что даст результат быстрее? Какие ресурсы нужны?
Формат: сравнительная таблица (сложность, сроки, ресурсы).
```

**Critic** (дьявол-адвокат):
```
Ты — devil's advocate. Предложи вариант, который никто не рассматривает.
Вопрос: [ВОПРОС]
Контекст: [КОНТЕКСТ]
Есть ли третий путь? Можно ли НЕ делать это вообще? Что если вопрос поставлен неправильно?
Формат: 1-2 альтернативы с обоснованием.
```

### Шаг 3: Синтез

Собрать все 4 ответа. НЕ выбирать победителя — показать пользователю:

```
## Council: [вопрос]

### Architect (стратегия)
[ключевые пункты]

### Skeptic (риски)
[ключевые риски]

### Pragmatist (реализуемость)
[таблица]

### Critic (альтернатива)
[неожиданный вариант]

### Рекомендация
[взвешенный вывод с учётом всех 4 голосов]
```

Решение — за пользователем.
