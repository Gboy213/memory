# Этап 07 — Bug-hunt в горячих местах

Сам строишь гипотезы и пытаешься воспроизвести по коду, логам и данным (read-only).
Невоспроизведённая гипотеза — не находка; закрытые гипотезы записываются.

Горячие места (сверху вниз; замени на свои):
1. Расчёты денег: арифметика на границах — пустой период, деление на 0, округление, NULL;
   сверь выборку из БД с тем, что считает отчёт.
2. Права доступа: фильтр по роли на каждом эндпоинте (только чтение кода + неавторизованный GET).
3. Жизненный цикл сущностей: записи, зависшие в статусе дольше N дней.
4. Пользовательские сценарии: состояния, которые ломают оформление/отправку.
5. Каналы данных: дни без записи, задвоения, конфликты источников.
6. Свежие коммиты за 14 дней — типовые регрессии свежих правок.

3–5 гипотез глубоко лучше 15 поверхностно. Мелкий баг с тестом — чини сам.
Секция «Закрытые гипотезы» обязательна.
