# Этап 06 — Отказные сценарии

Каждая находка: когда X → произойдёт Y → увидим Z (или НЕ увидим — это и есть баг).

1. Логи сервера за 7 дней (read-only): journalctl сервисов, логи cron, отчёты прошлых
   ночей — повторяющиеся ошибки.
2. Внешние API: 401/429/timeout/частичный ответ — что делает код, есть ли алерт.
3. БД: lock / отсутствие файла / создание пустышки при «просто чтении».
4. Частичный отказ многошаговых мутаций (деньги, договоры, файлы, бэкапы): упал на
   середине и соврал об успехе.
5. Состояние после рестарта сервиса; свободное место, рост логов/БД/бэкапов.

Защиту ≤30 строк с тестом — чини сам; остальное — «Ждёт решения» с обнаружением и защитой.
