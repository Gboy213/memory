# Этап 05 — Документация против кода и фактов

Нейтральные доки всех контуров: `*/context.md`, `*/decisions.md`, `*/current-focus.md`,
`*/system-map.md`, `rules/*.md`, корневой `AGENTS.md`. Файлы `CLAUDE.md` проверяются
только в ночь, когда PRIMARY=claude; Codex/Kimi их не читают.

1. Сторожа и линтеры доков репо, если есть.
2. Факты: пути, команды, числа, статусы, даты — сверь механическим следом (файл есть?
   команда работает? число из кода/БД?). Неверно и вводит в заблуждение — чини сам.
3. Относительные markdown-ссылки — битые чини.
4. Одно знание в двух местах с разным значением — приведи к источнику истины.
5. Планы `*/plans/*.md` со `status: active` против факта в git; закрытые — в «Ждёт решения».
6. `current-focus.md` > 300 строк — находка «свернуть» в «Ждёт решения».

Стиль, формулировки, порядок разделов — не находки.
