# Этап 03 — Качество кода

Только механически проверяемые дефекты по контурам из таблицы контракта.

1. `python3 -m py_compile` / `node --check` по изменённым за 14 дней файлам
   (`git log --since="14 days ago" --name-only`), потом по остальным, если есть время.
2. Мёртвый код и orphan-модули: внешний `rg` по имени ДО вывода; re-export не orphan.
3. Дубль логики: две функции делают одно и то же семантически (докажи) — в «Ждёт решения».
4. Исключения на API-границах с учётом глобальных handlers; silent failure после HTTP-ошибки в JS.
5. Секреты/PII в коде и git: проверять и текущее дерево (`git ls-files`), и историю
   (`git log --all -- <path>`).

Мелкий подтверждённый дефект (≤30 строк, есть тест) — чини сам по процедуре правки.
