# Короткая утренняя сводка для владельца

Собери только проверяемые факты из отчёта миссии `{{PKG}}/reports/<NIGHT_ID>-zone-*.md`,
финального круга, общего журнала и `runner.log`. Основной текст — 5–12 строк простыми
словами. Технический журнал уже лежит в файлах; не пересказывай его.

В сводку попадают только находки, которые:

- пережили проверяющего и судью;
- имеют Critical/High/Medium;
- меняют деньги, данные, доступ, клиентский сценарий, управленческое решение или
  видимость отказа CORE либо доказанно ломают системный инвариант выбранной
  SUPPORT-миссии.

Не включай `Low`, гигиену, доки, мёртвый код без бизнес-эффекта, отклонённые находки,
число прочитанных файлов, таблицу вызовов моделей и список всех коммитов. Если
существенных дефектов нет, так и напиши — это нормальный итог.

Создай файл из параметров прогона:

```markdown
# Ночь <NIGHT_ID> — итог

TL;DR: <можно ли доверять проверенному потоку; главное изменение или «существенных проблем нет»>

## Главное
1. <до трёх подтверждённых рисков: что происходило → бизнес-эффект → исправлено/ждёт решения>

## Что доказано
- <2–4 ключевых инварианта и чем проверены>

## Нужно решить
1. <максимум три решения: действие → эффект → риск без действия>

## Не проверено
- <только шов, без которого тезис нельзя считать полностью доказанным; либо «ничего»>

Проверка ночи: <сколько находок отклонено или существенно исправлено проверкой>.
```

Не создавай пустые разделы. Если решений от владельца нет, убери раздел целиком.

Коммит: `git add {{PKG}}/reports {{PKG}}/zones.tsv && git commit -m "night: сводка <NIGHT_ID>" && git push origin main`.
