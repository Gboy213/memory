# /night — вечером запустить, утром рассказать

Мотор: `~/.agents/skills/night/run.sh` (движок). Пакет репо — папка `night/` в корне
репозитория: контракт `contract.md`, реестр миссий `zones.tsv`, формат сводки
`summary.md`, отчёты `reports/`. Нет папки `night/` — сначала создай её из
`~/.agents/skills/night/package-template/` по README движка и согласуй с пользователем
контракт и миссии; без этого ночь не стартует.

Ты только запускаешь и объясняешь; сам аудит не делаешь. Пользователь может быть не
программистом: объясняй простыми словами, без имён функций и путей в основном тексте.

Все команды — из корня репо. `LOCK=/tmp/night-<имя папки репо>.lock`.

## Определи режим
- Идёт ли ночь: `[ -d /tmp/night-<repo>.lock ]`.
- Есть ли сводка за сегодня/вчера: `ls -t night/reports/*-summary.md | head -1`
  (свежее последнего запуска).

### Режим «вечер» (lock нет, свежей сводки нет, или пользователь просит запустить)
1. Если пользователь назвал тему — найди миссию в `night/zones.tsv` по колонке
   `runtime` (бизнес-результат) и `id`. Неочевидное соответствие — спроси, одной
   строкой на вариант. Без темы — автоматический выбор (давность + cooldown 7 дней).
2. `bash ~/.agents/skills/night/run.sh --dry-run [--only <миссия>]` — покажи одной
   строкой: бизнес-миссию, ведущую модель, проверяющего и судью.
3. Дерево должно быть чистым и на main — иначе скажи, что мешает, и остановись.
4. Запуск в фоне: `nohup bash ~/.agents/skills/night/run.sh [--only <миссия>] > /dev/null 2>&1 &`
   (Claude Code: запусти через Bash с `run_in_background`, чтобы утром получить
   уведомление и сразу сделать выжимку в этом же терминале).
5. Ответь в 3 строки: какой поток проверяется от начала до конца, какая модель ведёт и
   какие проверяют, где лог (`night/logs/<дата>/runner.log`), как остановить
   (`kill <pid из runner.log>`; после kill -9 — `rmdir /tmp/night-<repo>.lock`).
   Напомни: ноут не закрывать. Codex/Kimi: добавь «утром напиши `/night` в этом же
   терминале — покажу выжимку» (уведомления о завершении фона у них нет).

### Режим «идёт» (lock есть)
`tail -5 night/logs/<дата>/runner.log` → одной строкой: какая миссия, сколько идёт.

### Режим «утро» (сводка появилась / раннер завершился)
1. Прочитай сводку `night/reports/<дата>-summary.md` и отчёт миссии
   `night/reports/<дата>-zone-*.md`.
2. Расскажи простыми словами, 5–12 строк: доказан ли бизнес-тезис; до трёх
   существенных находок; что уже починили и задеплоили (с уверенностью: тесты
   зелёные, деплой прошёл); что ждёт «да» — пронумерованным списком, каждое:
   суть → почему не сделали сами → что изменится → риск; что не успели.
3. Жди ответа. «да N» → примени патч из отчёта миссии (diff в секции «Ждёт решения»),
   тесты, коммит `night-morning: …`, push, деплой по таблице контуров из
   `night/contract.md`, короткий отчёт. «нет N» → пометь в сводке «отклонено» и закоммить.
4. Вопросы по одному, простыми словами, с контекстом.

## Не делай
- Не запускай два раннера (lock). Не запускай несколько миссий за одну ночь и не
  превращай инженерную гигиену в добычу.
- Не правь ночные коммиты вручную без просьбы — только через «да/нет».
- Не запускай ночь без согласованного с пользователем `contract.md`: там границы того,
  что модели могут менять сами.
