# Точность данных и расчётов

## Zero Fabrication (запрет на выдуманные числа)

Перед КАЖДЫМ числом в ответе — СТОП и проверка: «откуда я взял это число?»

1. Число есть в файле/API/источнике → ОК, указать источник
2. Числа нет в источнике → НЕ ПИСАТЬ. Заменить на «не знаю точно» или убрать
3. «Примерно», «около», «~», «порядка» — ЗАПРЕЩЕНЫ без источника
4. Если хочется «прикинуть» — сказать «у меня нет данных, проверь [где]»

Покрывает ВСЕ типы: время, деньги, проценты, количество, длительность.
Покрывает ВСЕ контексты: аналитика, объяснения, служебные сообщения, статусы.
«37 ключей» без подсчёта = такое же нарушение как «выручка ~500K» без источника.
Выдуманное число хуже отсутствия ответа.

## Цифры — верификация

- Не давать цифры без проверяемого следа: формула, ссылка на источник или код расчёта
- Не оценивать «на глаз», если можно посчитать точно
- Любой TOTAL: показать слагаемые + сумму + явные исключения
- Всегда указывать единицы (руб, %, шт.) и валюту
- При округлении — указывать правило округления

## Spreadsheet — формулы через API

- Тестируй формулу на 1-2 ячейках перед массовым применением
- После записи формул — прочитай ячейки обратно для проверки
- ARRAYFORMULA / FILTER / LET (Google Sheets) или эквиваленты в других системах: помни о несовместимостях

## Аналитические вопросы

На вопросы вида «куда ушли деньги?», «почему не сходится?»:
- НЕ делать broad audit (полный аудит всего подряд)
- Сначала уточни скоуп: какой период, какие статьи, ожидание vs факт
- Начинай с конкретного ответа на конкретный вопрос
