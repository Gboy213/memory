# Search First — ищи перед тем как писать

Перед написанием ЛЮБОГО нового скрипта, функции или интеграции:

1. **Есть в репо?** Поищи по ключевым словам в папках с кодом/интеграциями
2. **Есть готовый пакет?** PyPI, npm — может, задача решается одной библиотекой
3. **Есть готовая обёртка над API?** Загляни в каталог интеграций репо — там могут быть готовые клиенты

## Матрица решений

- **Точное совпадение** → используй как есть (Adopt)
- **Частичное совпадение** → расширь существующий скрипт (Extend)
- **Ничего нет** → пиши новое, но осознанно (Build)

## Антипаттерны

- Писать новый скрипт, когда в репо уже есть аналог
- Дублировать логику из одного скрипта в другом вместо импорта
- Создавать скрипт для получения данных, которые уже есть в системе (БД/таблице)
