# Старт сессии

В начале каждой сессии — **молча** выполни:

1. `git checkout main && git pull --ff-only origin main` — подтянуть изменения. Только `main` (если в проекте принят monorepo-flow без feature-веток; иначе скорректировать под свой workflow).
2. Если есть новые коммиты от соавторов или ботов — бегло глянуть `git log --oneline -5` и сообщить что изменилось.
3. Если конфликты — сообщить, не резолвить автоматически.
