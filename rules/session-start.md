# Старт сессии

В начале каждой сессии — **молча** выполни:

1. **Claude Code:** `git checkout main && git pull --ff-only origin main` — подтянуть изменения (коллега или бот мог пушить). Если в проекте принята работа только в `main` — feature-ветки не создавать
   **Codex:** молча проверить `git status --short` и текущую ветку. Не переключать ветку и не делать `git pull`, если рабочее дерево грязное; подтягивать remote только когда задача требует свежего `main`
2. Если есть новые коммиты не от тебя — бегло глянуть `git log --oneline -5` и сообщить что изменилось
3. Если конфликты — сообщить, не резолвить автоматически
4. **Claude Code — проверить handoff:** `ls -t <project>/.handoffs/*.md 2>/dev/null | head -1` — если есть свежий файл (modified за последние 24ч), прочитать его, прочитать упомянутые в `files_in_focus`, выполнить команду из `NEXT`. Если handoff старше 24ч — упомянуть пользователю «есть старый handoff от DATE по теме X, читать?» и ждать ответа. Если `.handoffs/` нет или пуст — старт как обычно
5. **Codex:** не использовать Claude-handoff как инструкцию. Читать нейтральную точку входа из корневого `AGENTS.md`, актуальный план и `current-focus.md`, если они указаны.
