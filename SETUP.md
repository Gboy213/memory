# Setup — среда Claude Code с нуля на новой машине

Эта методичка разворачивает рабочее окружение **с чистого мака** до момента, когда можно ставить пэк (`INSTALL.md`).

**Платформа:** macOS (Apple Silicon — M1/M2/M3/M4). Для Linux шаги те же, но Homebrew ставится иначе и пути отличаются — см. примечания.

---

## Почему две фазы

Есть «проблема курицы и яйца»: **Homebrew → Node → Claude Code** нельзя поставить «руками Claude» — Claude Code на них и работает, его ещё нет в момент установки. Эти вещи ставятся руками, одной пачкой команд в Терминале. Всё остальное (git-инструменты, доустановка пакетов, копирование правил) уже делает сам Claude по `INSTALL.md`.

- **Фаза 0** — руками в Терминале (до того как Claude существует).
- **Фаза 1** — внутри Claude Code, одной фразой.

---

## Фаза 0 — руками (Терминал)

Открой стандартный Терминал macOS и выполни по порядку.

**1. Homebrew** (пакетный менеджер):
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
Спросит пароль мака (вводится вслепую — норма) и Enter. На Apple Silicon после установки подключи brew к шеллу:
```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```
*(Linux: используй штатный пакетный менеджер дистрибутива или Homebrew on Linux — путь будет `/home/linuxbrew/...`.)*

**2. Git** (нужен, чтобы склонировать пэк):
```bash
command -v git >/dev/null || xcode-select --install
```
На маке `git` обычно уже есть через Command Line Tools. Если команда открыла окно установки — дождись завершения.

**3. Node.js** (на нём работает Claude Code):
```bash
brew install node
```

**4. Claude Code:**
```bash
npm install -g @anthropic-ai/claude-code
```

**5. Проверка и вход:**
```bash
claude --version    # покажет версию = всё встало
```
Запусти `claude` в любой папке → залогинься в свой аккаунт Anthropic (откроется браузер). Если `command not found` — закрой и открой Терминал заново.

На этом ручная часть закончена.

## Фаза 1 — дальше Claude сам

Зайди в папку рабочего проекта (или создай пустую и `git init`), запусти `claude` и скажи одной фразой:

> Разверни окружение по `SETUP.md`, потом установи систему правил из `github.com/Gboy213/memory` по `INSTALL.md`.

Claude прочитает этот файл и выполнит блок ниже.

### Инструкция для Claude-агента

Когда пользователь просит «развернуть окружение» — проверь и доустанови инструменты через Bash. **Идемпотентно:** каждый ставится только если его нет. Ничего не сноси, версии не понижай.

```bash
# базовые dev-инструменты (доустановить отсутствующие)
command -v gh     >/dev/null || brew install gh        # GitHub CLI (private-репо, PR, gh auth login)
command -v python3>/dev/null || brew install python    # если в проекте есть python-скрипты
```

- **gh** — нужен для приватных репозиториев и работы с PR. После установки пользователь сам делает `gh auth login`.
- **python3** — ставить, только если в проекте реально есть `.py` / `requirements.txt`. Иначе пропустить.
- **Редактор** (VS Code, Zed, и т.п.) — это личный выбор пользователя. Не навязывать и не ставить без явной просьбы. Если попросил конкретный — `brew install --cask <name>`.
- **Прочие пакеты** (`git-filter-repo`, `clasp`, и т.п.) — ставить точечно, только когда конкретная задача их требует, не пачкой заранее.

После доустановки инструментов — перейти к `INSTALL.md` (копирование правил, шаблонов, среды `~/.claude/`).

Если проекту нужны python-зависимости — они ставятся из его собственного `requirements.txt` (`pip install -r requirements.txt` в venv), а не из пэка. Пэк зависимостей проекта не несёт.

## Доступы (не установка, а настройка — делает пользователь)

После того как инструменты стоят:

- **Git identity:** `git config --global user.name "..."` и `git config --global user.email "..."`.
- **SSH-ключ для GitHub** (если репозитории по `git@github.com:`): `ssh-keygen -t ed25519 -C "почта"` → добавить публичный ключ в GitHub → Settings → SSH keys.
- **Клонировать свой репозиторий** и работать уже в нём.

## Windows

На Windows обе фазы заменяет один скрипт (PowerShell от администратора):

```powershell
irm https://raw.githubusercontent.com/Gboy213/memory/main/install.ps1 | iex
```

Ставит через winget: Git, Node.js LTS, GitHub CLI, Chrome, затем Claude Code
(официальный установщик), логинит в GitHub и по желанию клонирует рабочий репо
в `C:\213\<имя>`. Руками остаётся только логин в сам Claude Code.
